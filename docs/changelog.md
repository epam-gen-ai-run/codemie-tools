# Changelog

All notable changes to CodeMie Tools will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Comprehensive MkDocs documentation with Material theme
- Complete XLSX tool documentation (overview, API reference, usage guide, filtering, statistics, examples)
- GitHub Actions workflow for automatic documentation deployment
- Getting started guides (installation, quick start)
- Toolkits overview page

### Changed
- Documentation now hosted on GitHub Pages
- Improved package structure documentation

## [0.1.7.0] - 2024

### Added
- Code executor tool for safe code execution
- Enhanced Excel processing capabilities with filtering
- Statistics generation for Excel files

### Changed
- Updated dependencies for better compatibility
- Improved error handling across all tools

## [0.1.3.2] - 2024

### Added
- Initial public release
- File Analysis Toolkit (XLSX, PDF, DOCX, PPTX)
- Project Management Toolkit (Jira, Confluence)
- Data Management Toolkit (Elasticsearch, SQL, File System)
- Access Management Toolkit
- Notification Toolkit (Email, Telegram)
- Code Quality Toolkit (SonarQube)
- Version Control Toolkit (GitLab, GitHub, Git)
- QA Toolkit (Zephyr)
- ReportPortal Toolkit
- Research Toolkit (Google Search, Wikipedia)
- Cloud Toolkit (AWS, Kubernetes)
- Vision Toolkit
- LangChain integration
- Pydantic-based configuration models

### Core Features
- Base toolkit architecture
- Auto-discovery system for toolkits
- Comprehensive error handling
- Type-safe configurations
- Extensive test coverage

## Version History

- **0.1.7.0** - Current version with code executor and enhanced Excel features
- **0.1.3.2** - Initial public release with core toolkits
- Earlier versions were internal development releases

## Upgrade Guide

### Upgrading to 0.1.7.0

```bash
pip install --upgrade codemie-tools
```

No breaking changes. All existing code should continue to work.

### Upgrading to 0.1.3.2

First public release - no upgrade path needed.
